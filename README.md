## 🏁 Project Grid

These are **planned portfolio projects**, not completed analyses. Each will have its own repository, reproducible workflow and clear findings as it develops.

### 01 · Formula 1 Race Performance Analysis

**The question:** What patterns connect qualifying position, lap times and race results?

- Explore publicly available F1 race data and identify performance trends.
- Clean and analyse results with **Python and Pandas**.
- Communicate findings through charts and a **Power BI** dashboard.
- Document assumptions, limitations and insights in a project README.

**Planned stack:** `Python` · `Pandas` · `Matplotlib` · `Power BI`

**Status:** 🟡 Planned

### 02 · Vehicle Fuel Efficiency & Cost Dashboard

**The question:** How do distance, fuel consumption and fuel prices affect driving costs?

- Structure and clean a sample vehicle-cost dataset.
- Calculate fuel efficiency and cost-per-kilometre metrics.
- Visualise changes over time and explore potential savings.
- Translate the results into practical recommendations.

**Planned stack:** `Excel` · `Python` · `Power BI`

**Status:** 🟡 Planned
