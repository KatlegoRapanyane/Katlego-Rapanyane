# My Data Journey — GitHub Pages Portfolio

A responsive, single-page portfolio for Shaper Phase 2: My Portfolio and Learning Roadmap.

## Contents
- Mini bio, target domain and Data Analyst role
- Two realistic seed project ideas (Formula 1 and vehicle fuel efficiency)
- Technical and soft skills to grow
- 30-day and 6-month learning goals

## How to publish
1. Sign in to GitHub.
2. Create a **public** repository named `YOUR-USERNAME.github.io` (replace `YOUR-USERNAME` with your real GitHub username).
3. Upload `index.html` to the repository root. `README.md` is optional.
4. Commit the files to the `main` branch.
5. In repository **Settings → Pages**, select **Deploy from a branch**, `main`, `/ (root)`, and Save.
6. Wait for GitHub Pages to deploy, then open `https://YOUR-USERNAME.github.io`.
7. Check the mobile and desktop layout and all navigation links. Submit that live URL to Moodle.
